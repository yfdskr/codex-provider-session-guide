# 账号、API 与平滑切换

2026-10-29 · 0.6.0 预发布版；安装包从 GitHub Releases 下载。

## 首次设置

1. 安装 `extension/artifacts/codex-provider-manager-0.6.0.vsix` 到当前 SSH 服务器，等当前 Codex 任务结束后重新加载窗口。
2. 打开「Codex 管理：打开可视化管理中心」，确认左下角是 **0.6.0**、机器正确。后台版本较旧时，在总览点「升级后台」；需先停止代理、暂停监控和定时备份。
3. 在总览的「平滑切换」点 **启用本机平滑切换**，阅读说明并确认。
4. 等当前任务结束，点 **重新加载窗口**。回到管理中心，确认平滑切换显示 **已启用**。

首次设置完成后不用重复启用。兼容模式只调整这台机器的官方扩展入口文件，官方原程序和入口均保留副本，不改全局编辑器设置、账号或对话。当前适配 Linux x64、官方扩展 `26.51007.21434` 的已验证程序。

官方扩展更新后先检查状态；不兼容时不能使用重载切换，不要强行替换版本号。恢复入口后可重新安装官方扩展，等待新版本适配。

## 添加账号或 API

- **官方账号：**「供应商」→「新增官方账号」→取名→「登录」→打开官方授权页面输入验证码→回面板刷新，确认已保存。新增账号不改变当前登录。
- **保存当前官方账号：**点同名按钮并确认，仅支持文件登录缓存。账号文件等同密码，保存在本机受限目录，不上传供应商。
- **API：**「添加 API」→填写名称、基础地址和准确的模型 ID→保存→「设置」填写 Key。地址填写到 `/v1`，不要加 `/responses`。
- **检查：**先点「检查配置」，不联网；文字连接与工具格式测试由你主动点击，可能收费。仅支持 Chat Completions 的接口暂不能直接使用。

「已保存登录」不保证令牌仍有效；「上次应用」也不代表所有旧窗口都已切换。请在官方 Codex 核对实际身份。

## 日常切换

1. 等当前 Codex 任务结束，在目标账号或 API 卡片点「切换」。
2. 核对目标，点 **切换并重新加载**，确认任务已结束。
3. 当前窗口自动重载。新 Codex 等后台备份、切换和检查完成后再启动；管理中心自动重新打开并显示进度。
4. 确认成功，在官方 Codex 核对账号，找到原对话继续。

无需关闭 VS Code、重新连接服务器、复制命令或找进程。其他窗口或 CLI 仍在线时会等待，可在管理中心取消；不会结束它们。切换期间不要更新官方扩展或另外启动 Codex。

「安排稍后切换」保留当前窗口，等所有 Codex 自然退出才处理。取消和失败后，监控、代理及定时备份不会自动恢复。

## 出错怎么处理

| 提示 | 操作 |
| --- | --- |
| 入口已安装，等待首次重载 | 等任务结束，点「重新加载窗口」完成启用 |
| 平滑切换需要更新 | 重新启用兼容模式，再重载一次 |
| 官方扩展版本尚未适配 | 暂不使用重载切换；等待适配，或使用现有稍后切换流程 |
| 正在等待其他 Codex | 等其他窗口任务结束，或取消本次切换；不必手动结束进程 |
| 备份失败，尚未开始修改 | 按错误检查磁盘、Python 和记录完整性，修复后重新创建计划 |
| 切换结果未知 | 保留备份，先核对账号及对话，不重复运行或覆盖恢复 |
| 启动入口或原程序无法核对 | 停止切换，保留备份；可重新安装官方 Codex 扩展恢复原程序，不删除 `.codex` |

要撤销兼容模式：总览 → **恢复官方启动入口** → 等任务结束 → **重新加载窗口**。账号、配置和对话保留。卸载本管理器前先完成这一步。
