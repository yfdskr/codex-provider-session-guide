
GitHub 登录用户应为 `yfdskr`。维护者核对工作区、验证报告与附件后，通过 `scripts/publish-github.sh` 创建或使用指定的公开仓库，推送 `main` 和 `v0.6.0`，创建预发布 Release 并附校验文件。脚本不强制覆盖远程历史、旧标签或已有 Release。
