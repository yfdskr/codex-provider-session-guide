# 更新记录

## 0.6.0 · 2026-10-26

- 增加可撤销的本机平滑切换兼容模式，首次在总览启用并重载；只适配已验证的 Linux x64 官方扩展版本。
- 常用切换改为确认后只重载当前窗口，新 Codex 等待后台切换完成再启动；管理中心自动恢复进度。
- 安排、执行和启动前核对入口及当前窗口回执；版本变化、未知结果或记录损坏时停止，不强杀其他窗口。
- 保留官方原程序和入口备份，支持逐字恢复；不修改全局启动设置。
- 增加真实隔离 VS Code 的首次启用、重载切换、对话保留与撤销测试。

## 0.5.1 · 2026-10-26

- 修复同一对话 ID 存在多个记录文件时备份误拒绝，所有副本逐个保存、校验，不合并或删除，按唯一 ID 核对数据库。
- Python 切换程序返回执行阶段与是否开始修改；有可靠未修改回执的备份失败显示具体原因，未知结果仍不自动重试。
- 支持核对失败现场后创建新计划，保留原失败记录，旧计划保持停止。
- 增加不同正文的同 ID 副本、备份失败回执与真实 Codex 自动往返回归。

## 0.5.0 · 2026-10-26

- 常用账号/API 切换改为界面确认后自动暂停计划、检查代理并关闭当前窗口，由独立后台等待退出后备份、切换和校验。
- 等待记录持久保存，支持取消、一小时过期、重新连接查看结果；正在运行和未知的切换不会自动重放。
- 代理有请求、检测、备份或登录未完成时阻止关闭，不强杀 Codex；等待中冻结其他管理修改。
- 保留离线切换作为排错入口；增加等待、取消、重启、进程重现、部分失败和真实 Codex 隔离往返验证。
- 当前任务结束仍需用户确认；只自动关闭当前窗口，无法接管其他窗口任务。

## 0.4.1 · 2026-10-26

- 修复 Linux 切换前的进程检查误拦：受保护的 sshd、sd-pam 需核对 root 所属进程链接和系统父进程后才能排除。
- 对 Codex 与其他身份无法确认的进程继续阻止切换，错误显示具体进程编号；不读取命令行、环境变量或结束进程。
- 增加真实服务器场景的回归测试；旧版安装包和运行文件保留。

## 0.4.0 · 2026-10-26

- 多官方账号独立登录、保存当前文件登录、身份展示、刷新与移除；新增和登录不切换当前账号。
- 配置、文字流式与工具格式分别检查；模型测试需主动确认，不执行测试工具。
- 切换计划生成无密钥命令，关闭 Codex 后独立终端执行；配置、账号与完整会话分别备份，核对 ID 和正文。
- 保留已登记账号的最新登录缓存；计划过期、配置变化、活动进程或并发操作阻止执行，失败不重放。
- 新增后台升级入口，保留配置与密钥并更新用户服务。
- 仅本地预览；真实 OAuth、编辑器升级与供应商组合仍需用户验收。

## 0.3.0 · 2026-10-26

- 新增独立本机后台，代理、监控和定时备份在关闭或重载扩展后继续运行。
- 新增后台启动、停止、状态、操作结果查询，以及 Linux 用户服务安装和移除入口。
- 多窗口共享后台配置，陈旧版本保存会被拒绝；同一 Codex 目录只允许一套后台。
- API Key 迁移到受限本机目录，保留 SecretStorage 副本；状态与日志不返回 Key。
- 操作保存编号，崩溃后未知结果不自动重放；代理重启尝试保留原端口和令牌。
- 补充隔离的真实 Codex、强制崩溃、后台生命周期、用户服务流程与系统解析器检查。
- 仅本地试用；完整 VS Code 界面、真实退出 SSH、其他系统与真实供应商组合仍待安装验收。

## 0.2.0 · 2026-10-18

- 新增五页可视化管理中心、入门步骤、供应商表单和运行状态。
- 对话支持搜索、项目筛选、排序、分页、多选与信息弹窗。
- 新增监控时间表单，默认北京时间，显示最近连接变化。
- 新增备份列表、逐文件校验、定时备份和不含隐私的诊断复制。
- 新增官方/API 切换向导，独立终端先备份、同步，再核对会话 ID 与正文。
- 补充真实 Codex 与同步工具往返联调、浏览器交互及主题测试。
- 仅生成本地 VSIX，不发布；代理与定时任务仍依赖窗口存活。

## 0.1.1 · 2026-10-17

- 自动识别已有 API，启动和刷新时补入列表，不读取 Key 或执行认证命令。
- 显示官方账号入口，并标记当前配置使用的供应商；不改现有接口及登录状态。
- API 分组默认展开，避免已识别的供应商藏在折叠列表中。

## 0.1.0 · 2026-10-17

- 新增供应商分组、隐藏录入 Key、优先级和虚构短句检测。
- 新增本机 Responses 代理，支持明确错误后的备用供应商选择。
- 新增按项目查看对话、搜索、批量归档与删除；写操作前完整备份。
- 新增可配置的监控间隔、超时、失败阈值、恢复等待和生效时段。
- 默认关闭代理和监控，不自动改写现有 Codex 配置；仅提供预览 VSIX。
